# athal7/tap

Personal Homebrew tap for developer tools by [@athal7](https://github.com/athal7).

## Install

```sh
brew tap athal7/tap
```

## Tools

### opencode-cmd

Shell CLI for the [OpenCode](https://opencode.ai) HTTP API.

```sh
brew install athal7/tap/opencode-cmd
```

See the [opencode-cmd repo](https://github.com/athal7/opencode-cmd) for full documentation.
